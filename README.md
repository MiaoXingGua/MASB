## 功能列表

### 基础操作
- 🎮 **启动游戏**：自动启动游戏并进入主界面
- 🎁 **接受贡礼**：一键领取所有可收取的贡礼
- 📩 **收取信息**：自动读取并处理所有新信息

### 古堡系统
- 🌍 **八方游历**：自动执行古堡八方游历相关操作
- 🏛️ **议事阁**：处理古堡议事阁各类事务

### 商店系统
- 🏪 **免费商店**：访问人偶商店杂货铺，自动领取/购买免费物品
- 🧛 **献血商店**：自动访问人偶商店的鲜血商店

### 社交系统
- 👫 **好友-一键收赠**：批量收取好友赠送并回赠
- 🔄 **好友-清理好友**：自动清理不活跃好友
- 📥 **好友-申请好友**：通过好友申请并主动拓展新好友

### 忘却中庭
- ⚔️ **英灵剑冢**：自动挑战英灵剑冢
- ⏳ **时计塔楼**：自动探索时计塔楼
- 🌌 **通天深渊**：自动挑战通天深渊
- 🎭 **斗技场_竞演赛**：参与斗技场竞演赛
- 🔥 **斗技场_死斗赛**：参与斗技场死斗赛

### 其他功能
- 🏢 **氏族**：处理氏族日常相关事务
- 📋 **任务**：领取任务奖励并完成可自动完成的任务

## 使用教程

1. 首次使用请完成初始化配置
2. 在功能列表中勾选需要执行的任务
3. 点击"开始运行"按钮启动自动化流程

详细操作说明请参考 [用户手册](docs/zh_cn/usage.md)（持续更新中）
